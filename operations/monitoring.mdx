Open [Monitoring & Alerts](https://osint.ly/monitoring) from the selected Personal or organization workspace. Access depends on the workspace plan and permissions. The dashboard shows summary counts and three tabs: **Alerts**, **Monitors**, and **Channels**.

## Create and manage monitors

Select **Create Monitor**, give the monitor a name and target, choose the check type, rules, and frequency, then save it. The available check types are:

| Type | What it checks |
| --- | --- |
| Email Registration | Changes in account registration signals for an email address |
| Module Query | Results from selected search modules and configured rules |
| Global Search | New findings from a scheduled search for the selected input |

The form shows an estimated run cost. Available frequencies are hourly, every six hours, daily, and weekly. The number of monitors you may create depends on the selected workspace's plan. Existing monitors can be edited, paused, resumed, or deleted when your role permits it. The **Monitors** tab shows status, target, frequency, and latest run.

## Review alerts

The **Alerts** tab lists findings, severity, status, target, creation time, and—within an organization—the member who created the monitor. You can update alert status or delete an alert where permitted. Open the related investigation or run a fresh search to verify a finding; provider data can change between scheduled runs.

## Notification channels

The **Channels** tab configures workspace-level delivery. Email and Discord settings apply to every monitor in the selected workspace. Organization owners and admins can manage channels; other members can view the available settings according to their permissions. Check the current form for supported delivery options and test a destination before relying on notifications.

## Workspaces, credits, and time

Monitoring uses the selected workspace. Its plan controls access and monitor count, and its permissions control who can create monitors and manage channels. Review the displayed run estimate and the workspace's credits before saving frequent checks.

**Every date and clock time displayed in the Osintly interface is in UTC.** This includes alert creation times and monitor run times. Relative labels such as “2 hours ago” are elapsed time from the underlying UTC timestamp; they do not imply a separate local timezone.
