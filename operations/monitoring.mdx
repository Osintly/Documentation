<Warning>
The current Monitoring & Alerts experience is being retired and will be replaced by **Security Watch**, Osintly’s new security monitoring product. Do not create new monitors in the legacy interface.
</Warning>

The existing Monitoring dashboard may still show previously created monitors, alerts, and notification channels while the transition is in progress. Its availability, limits, and delivery behavior should not be treated as a commitment for new investigations.

---

## What to do now

- Use full searches and focused tool lookups for current checks.
- Save important searches in the correct Personal or organization workspace so they remain available from history.
- Export or record the context of existing legacy-monitor investigations where required by your workflow.
- Follow product updates for Security Watch availability and migration guidance.

## Existing legacy monitors

If you still need to review the legacy interface:

1. Open [osint.ly/monitoring](https://osint.ly/monitoring).
2. Review current monitor state and alert history.
3. Avoid relying on it for new operational coverage.
4. Contact [support](https://osint.ly/support) if an existing monitor needs attention during the transition.
