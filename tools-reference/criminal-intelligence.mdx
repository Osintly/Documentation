Criminal Intelligence endpoints accept a person name, organization, or keyword. `POST /search` is validation-only: it normalizes the query type and does not call providers or consume credits.

```json
{
  "value": "Tayler Anthony Smith",
  "type": "name"
}
```

---

## Search types

Canonical types:

- `name`
- `organization`
- `keyword`

Aliases:

- `person`, `full_name`, and `individual` -> `name`
- `company`, `entity`, and `org` -> `organization`
- `query`, `text`, and `term` -> `keyword`

Optional controls:

- `limit`: `1` to `50`, default `20`
- `interpolNoticeTypes`: `red`, `yellow`, `un`
- `fdaCategories`: `drug`, `food`, `device`

---

## Endpoint groups

| Operation | Endpoint | Cost | Notes |
|---|---|---:|---|
| Search | `POST /tools/criminal-intelligence/search` | Free | Validates and normalizes only. |
| Interpol | `POST /tools/criminal-intelligence/interpol` | 1 | Red, Yellow, and UN notices through a cached Jina Reader fetch. |
| FBI Wanted | `POST /tools/criminal-intelligence/fbi-wanted` | 1 | FBI Most Wanted records, photos, warnings, rewards, and case metadata. |
| DOJ | `POST /tools/criminal-intelligence/doj` | 1 | DOJ press releases for convictions, indictments, arrests, and penalties. |
| SEC | `POST /tools/criminal-intelligence/sec` | 1 | SEC EDGAR filing search for enforcement and regulatory context. |
| FDA | `POST /tools/criminal-intelligence/fda` | 1 | FDA enforcement and recall records across drug, food, and device categories. |
| All | `POST /tools/criminal-intelligence/all` | 3 | Runs the main collectors and charges once. |

OpenSanctions is not included in this tool.

## Fast path

Validate an input before launching enrichment.

```bash
curl -X POST "https://api.osint.ly/tools/criminal-intelligence/search" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "Tayler Anthony Smith", "type": "person" }'
```

Use `/all` when you need the broad enforcement snapshot.

```bash
curl -X POST "https://api.osint.ly/tools/criminal-intelligence/all" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "Tayler Anthony Smith", "type": "name", "limit": 20, "interpolNoticeTypes": ["red"], "fdaCategories": ["drug", "food", "device"] }'
```

---

## Availability

The V1 providers do not require API secrets. In `/all`, secondary collector failures are returned in `data.partialErrors`.

Interpol is fetched through Jina Reader because Interpol's public API often blocks server egress with HTTP 403. The response is parsed back into the Interpol JSON shape.

---

## Caching

Provider responses are cached by collector, normalized query, and options. Interpol responses are cached for seven days; the other providers use shorter provider-level cache windows. Cache entries reduce repeated provider calls and do not change route pricing.
