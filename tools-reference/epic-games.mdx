---
title: Epic Games
description: Direct Epic Games account validation and enrichment endpoints for identifiers, linked accounts, tags, regions, creator data, friends, and achievements.
icon: gamepad
---

Epic Games endpoints accept one account identifier and return focused account intelligence. `POST /search` is validation-only: it normalizes the identifier type and does not call Epic or consume credits.

```json
{
  "value": "some-player",
  "type": "epic_display_name"
}
```

---

## Search types

Canonical types:

- `epic_display_name`
- `epic_account_id`
- `creator_code`
- `psn_username`
- `steam_username`
- `xbox_username`
- `psn_account_id`
- `steam_id`
- `nintendo_account_id`

Accepted aliases include `epic`, `epic_id`, `creator`, `psn`, `playstation`, `steam`, `steamid`, `xbox`, `xbl`, `xlb`, and `nintendo`.

## Endpoint groups

| Operation            | Endpoint                                      | Cost | Notes                                                          |
| -------------------- | --------------------------------------------- | ---: | -------------------------------------------------------------- |
| Search               | `POST /tools/epic-games/search`               | Free | Validates and normalizes only.                                 |

| Resolve              | `POST /tools/epic-games/resolve`              |    1 | Resolves the identifier to Epic account data.                  |
| Linked Accounts      | `POST /tools/epic-games/linked-accounts`      |    1 | Linked platform auths.                                         |
| Tags                 | `POST /tools/epic-games/tags`                 |    1 | Account tag metadata.                                          |
| Regions              | `POST /tools/epic-games/regions`              |    1 | Region and language signals.                                   |
| Friends Achievements | `POST /tools/epic-games/friends-achievements` |    2 | Friends, achievements, and social counters.                    |
| Creator              | `POST /tools/epic-games/creator`              |    1 | Affiliate, creator profile, social links, and creator islands. |

## Fast path

Validate an input before launching enrichment.

```bash
curl -X POST "https://api.osint.ly/tools/epic-games/search" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "some-player", "type": "xbox" }'
```

Use `/all` when you need a complete account profile.

```bash
curl -X POST "https://api.osint.ly/tools/epic-games/all" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "some-player", "type": "epic_display_name" }'
```

---

## Response data

`/all` returns one object per section in `data`. A section is `null` when it could not be collected, and the reason is listed in `data.partialErrors`.

- `resolve`: Epic account ID and display name.
- `linkedAccounts`: external platforms linked to the Epic account.
- `regions`: languages and play region.
- `friendsAchievements`: friend counts and achievement totals that are publicly visible.
- `creator`: Support-A-Creator code, published islands, and public creator profile (see below).
- `profileDb` and `tags`: community profile data and tags when available.

## Creator profile data

`POST /tools/epic-games/creator` and the `creator` section of `/all` can include a public Fortnite Creator profile in `data.profile`.

- `profile.found` is `true` only when the provider returns a valid Fortnite Creator page.
- When the profile is missing or invalid, `profile.found` is `false` and `profile.data` is `null`.
- Optional public fields remain `null` when unavailable: `bio`, `followerCount`, `images.avatar`, and `images.banner`.
- `profile.social` contains only recognized public social URLs.

The public profile fields are `bio`, `creatorPageUrl`, `displayName`, `followerCount`, `images`, and `title`.

## Caching

An Epic display name that no account uses returns `404 NOT_FOUND`. Provider responses are cached by collector and normalized identifier or account ID:

| Collector | Cached for |
|---|---|
| Resolve (display name or linked ID to account ID) | 24 hours |
| "Not found" answers | 6 hours |
| Suggestions | 1 hour |
| Linked accounts and regions | 1 hour |
| Creator, friends and achievements, and Fortnite Battle Royale stats | 30 minutes |
| Creator profile, profile database, affiliate, tags, islands, and Save the World stats | 6 hours |

Cache entries reduce repeated provider calls and do not change route pricing.
