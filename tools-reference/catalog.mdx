Open the [Tools Registry](https://osint.ly/tools) with or without signing in. The catalog shows listed public tools, featured tools, and categories. Search by tool name or description, filter by search type or featured status, or open a category page. The available catalog is driven by published registry entries, so a tool's appearance can change independently of this documentation.

The OsintlyCloudflare application currently includes result pages for **IP Intelligence, Domain Intelligence, Epic Games, PlayStation Network, Reddit, Roblox, Social Club, Steam, Vehicle History Finder, and Xbox**. Select a tool to see its supported input, lookup options, and available history. Public catalog visibility does not guarantee that every operation is free: the web app applies [tool usage limits](/tools-reference/usage-limits), and Tools API execution requires an eligible API plan.

## Saved result workflow

Run a lookup from its tool page. For tools that save results, reopen the result from that tool's history or the shared [History](/guides/history) page in the selected workspace. IP and domain result pages load detailed sections progressively and offer an intelligence snapshot download. A saved result reflects the lookup when it was collected; opening it does not run a new lookup. Dates and clock times shown in tool result UI and history are displayed in **UTC**.

For API request and response contracts, start with [Tools Reference](/tools-reference/introduction) and the individual tool pages.
