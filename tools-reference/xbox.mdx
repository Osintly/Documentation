---
title: Xbox
description: Direct Xbox Live account validation and enrichment endpoints for profile, presence, social data, games, media, clubs, and title details.
icon: user
---

Xbox endpoints accept a gamertag or XUID. `POST /search` is validation-only: it normalizes the identifier type and does not call Xbox or consume credits.

```json
{
  "value": "SomeGamertag",
  "type": "gamertag"
}
```

---

## Search types

Canonical types:

- `gamertag`
- `xuid`

Aliases:

- `xbox`, `xbl`, and `username` -> `gamertag`
- `id`, `xbox_id`, and `xuid` -> `xuid`

---

## Endpoint groups

| Operation       | Endpoint                           | Cost | Notes                                                               |
| --------------- | ---------------------------------- | ---: | ------------------------------------------------------------------- |
| Search          | `POST /tools/xbox/search`          | Free | Validates and normalizes only.                                      |
| Suggestions     | `POST /tools/xbox/suggestions`     | Free | Gamertag search suggestions.                                        |
| Resolve         | `POST /tools/xbox/resolve`         |    1 | Resolves gamertag or XUID.                                          |
| Profile         | `POST /tools/xbox/profile`         |    1 | Identity, avatar, gamerscore, reputation, and profile fields.       |
| Presence        | `POST /tools/xbox/presence`        |    1 | Online state, current device, current game, and last seen.          |
| Social          | `POST /tools/xbox/social`          |    1 | Friend, follower, following, verification, and multiplayer summary. |
| Linked Accounts | `POST /tools/xbox/linked-accounts` |    1 | Linked external account metadata.                                   |
| Games           | `POST /tools/xbox/games`           |    1 | Title history and achievement summaries.                            |
| Media           | `POST /tools/xbox/media`           |    1 | Game clips and screenshots.                                         |
| Clubs           | `POST /tools/xbox/clubs`           |    1 | Club memberships and metadata.                                      |
| Title Detail    | `POST /tools/xbox/title-detail`    | Free | Title details and achievements for one `titleId`.                   |
| All             | `POST /tools/xbox/all`             |    3 | Runs the main collectors and charges once.                          |

`POST /tools/xbox/title-detail` also requires a numeric `titleId` in the body.

---

## Fast path

Validate an input before launching enrichment.

```bash
curl -X POST "https://api.osint.ly/tools/xbox/search" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "SomeGamertag", "type": "xbox" }'
```

Use `/all` when you need a complete Xbox profile without full per-title achievements.

```bash
curl -X POST "https://api.osint.ly/tools/xbox/all" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "SomeGamertag", "type": "gamertag" }'
```

Fetch title-specific details separately.

```bash
curl -X POST "https://api.osint.ly/tools/xbox/title-detail" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "SomeGamertag", "type": "gamertag", "titleId": "12345" }'
```

---

## Response data

`/all` returns one object per section in `data`. A section is `null` when it could not be collected, and the reason is listed in `data.partialErrors`.

- `resolve`: gamertag, unique gamertag, XUID, avatar, and up to 10 search matches.
- `profile`: display name, gamerscore, account tier, reputation, tenure level, bio, location, and preferred platforms.
- `presence`: online state, current device, last game, and last seen time.
- `social`: follower, following, and friend counts, verification and relationship flags, and party summary.
- `linkedAccounts`: external networks the player shows on the profile.
- `games`: title history with last played date, devices, Game Pass flag, and achievement progress.
- `media`: recent game clips and screenshots with dates, views, and media URLs.
- `clubs`: club memberships with the player's roles, member counts, and club metadata.

## Rate limits

When Xbox Live is busy, a request waits briefly instead of failing right away.

- If Xbox stays busy for about 15 seconds, the route answers `429 PROVIDER_RATE_LIMITED` with a `Retry-After` header and `retryAfter` in seconds.
- In `/all`, a collector that stays throttled is listed in `data.partialErrors` with `code: "PROVIDER_RATE_LIMITED"` and `retryAfter`; the other sections are still returned. A collector is never returned empty because of a rate limit.
- `/suggestions` is best effort and waits at most a few seconds, so it can answer `429` during busy periods while full lookups still succeed.
- Hidden or missing clips and screenshots are a real empty result: `media.gameClips` or `media.screenshots` is an empty list. If only one of the two cannot be loaded, the other is returned and the failure is listed in `partialErrors` (`media.clips` or `media.screenshots`).

## Caching

Provider responses are cached by collector and normalized gamertag or XUID:

| Collector | Cached for |
|---|---|
| Gamertag or XUID resolution | 24 hours |
| "Not found" answers | 6 hours, or the collector's own duration when shorter |
| Search and suggestions | 1 hour |
| Profile, presence, social, and linked accounts | 30 minutes |
| Clubs | 1 hour |
| Games (title history) | 6 hours |
| Title detail | 12 hours |
| Title achievements | 6 hours |
| Media | Not cached |

Cache hits do not change route pricing.
