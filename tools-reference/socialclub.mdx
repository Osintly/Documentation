title: Social Club
description: Direct Rockstar Social Club account validation and enrichment endpoints for profiles, linked accounts, crews, games, and friends.
icon: users
---

Social Club endpoints accept a Rockstar nickname or Rockstar ID. `POST /search` is validation-only: it normalizes the identifier type and does not call Rockstar or consume credits.

```json
{
  "value": "some-player",
  "type": "nickname"
}
```

---

## Search types

Canonical types:

- `nickname`
- `rockstar_id`

Aliases:

- `username`, `socialclub`, `social_club`, and `social-club` -> `nickname`
- `id`, `rockstar`, `rockstarid`, and `rockstar_id` -> `rockstar_id`

---

## Endpoint groups

| Operation | Endpoint | Cost | Notes |
|---|---|---:|---|
| Search | `POST /tools/socialclub/search` | Free | Validates and normalizes only. |
| Suggestions | `POST /tools/socialclub/suggestions` | Free | Cached account search suggestions. |
| Resolve | `POST /tools/socialclub/resolve` | 1 | Resolves nickname or ID to a Rockstar account. |
| Profile | `POST /tools/socialclub/profile` | 1 | Core profile fields and visibility flags. |
| Linked Accounts | `POST /tools/socialclub/linked-accounts` | 1 | Linked external services. |
| Crews | `POST /tools/socialclub/crews` | 1 | Crew memberships and metadata. |
| Games | `POST /tools/socialclub/games` | 1 | Game records exposed by the profile provider. |
| Friends | `POST /tools/socialclub/friends` | 2 | Collected contact sample and hidden flag. |
| All | `POST /tools/socialclub/all` | 3 | Runs the main collectors and charges once. |

---

## Fast path

Validate an input before launching enrichment.

```bash
curl -X POST "https://api.osint.ly/tools/socialclub/search" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "some-player", "type": "socialclub" }'
```

Use `/all` when you need a complete Social Club profile.

```bash
curl -X POST "https://api.osint.ly/tools/socialclub/all" \
  -H "Authorization: Bearer $OSINTLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "value": "some-player", "type": "nickname" }'
```

---

## Availability

Provider-backed routes require Rockstar provider authentication configured server-side. If `resolve` fails, enriched routes return an error. In `/all`, secondary collector failures are returned in `data.partialErrors`.

---

## Caching

Provider responses are cached by collector and normalized identifier or account ID. Cache entries reduce repeated provider calls and do not change route pricing.
