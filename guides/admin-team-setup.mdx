## Create an organization

1. Open the workspace menu in the sidebar.
2. Choose **Create organization**.
3. Set its name, select Pro or Ultimate, and choose the paid seat count.
4. Complete checkout, then select the organization from the workspace menu.

## Invite members

- Open **Organization → Members** and send invitations by email.
- Assign either Admin or Member when inviting.
- Review pending invitations regularly; each pending invitation reserves a paid seat.

## Permission model

- Owner: billing, seats, role changes, SSO, ownership transfer, and organization lifecycle.
- Admin: members, API keys, usage, and day-to-day organization administration.
- Member: searches, shared history, and read-only API key/usage access.

## Organization best practices

- Confirm the selected workspace before launching a search or creating an API key.
- Review member access, pending invitations, shared usage, and API keys regularly.
- Keep ownership with the person responsible for the organization subscription.

For the complete workflow, see [Organizations & workspaces](/collaboration/organizations) and [Members & permissions](/collaboration/team-collaboration).
