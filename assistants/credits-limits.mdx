An assistant uses the plan of the workspace it is connected to, with the same limits and credits as osint.ly. Nothing is billed separately.

---

## Full searches

A full search uses **1 credit** from the workspace balance, like on the website.

- **Searches you ask for** run right away. The assistant tells you that a credit was used.
- **Searches the assistant suggests**, for example on a new username it found, need your confirmation first. Each confirmation is tied to the exact target, so the assistant cannot spend it on another value.
- **A target searched in the last 7 days** is reopened for free. Ask for fresh results to run it again for 1 credit.

A search that does not start uses no credit.

---

## Tool limits

Focused lookups (IP, domain, platform accounts, vehicle) count toward the same five-minute, hourly and daily tool limits as the website. Ask *"Show my Osintly plan and usage"* to see what is left.

When a limit is reached, the assistant tells you when it resets. If your plan allows it, it can offer to spend **1 credit** to continue: it asks you first, and spends the credit only if the limit is really reached.

---

## Daily credit limit per app

You can cap what each app spends in 24 hours. In **Settings → Connected apps**, choose a limit next to the app: 1, 5, 10, 25, 50 or 100 credits per day, or **No credit limit**.

Once the limit is reached, the app cannot start a new full search or spend a credit on a lookup until the 24-hour window frees up. Reopening a recent search still works, since it is free. The assistant tells you that the limit was reached and where to change it.

---

## Connected apps per plan

Each plan sets how many apps you can connect to one workspace at the same time.

| Plan | Apps per workspace |
| --- | ---: |
| Free | Not available |
| Standard | 1 |
| Pro | 3 |
| Ultimate | 10 |

ChatGPT, Claude and Codex each count as one app. Reconnecting an app you already use does not take a new slot. When a workspace is full, disconnect an app or upgrade the plan.

---

## Organizations

In an organization workspace, the assistant uses the organization's plan, tool limits and shared credits. See [Credits explained](/guides/credits-explained#organization-credits).
