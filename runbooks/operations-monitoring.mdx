<Warning>
Legacy Monitoring is being retired. Do not create new monitors or build new operational workflows on it. Security Watch will replace this experience.
</Warning>

## Handling an existing monitor

1. Open the legacy Monitoring dashboard and record the monitor target, status, latest run, and any unresolved alerts.
2. Preserve investigation context in the correct Personal or organization history, notes, or export before the transition.
3. Pause or delete monitors that are no longer required.
4. For a live issue, use a new full search or focused tool lookup to validate the target instead of relying only on a scheduled legacy run.
5. Escalate delivery or data-retention concerns to [support](https://osint.ly/support).

## Transition checklist

- Identify legacy monitors that are still business-critical.
- Record their target, intended cadence, notification recipients, and current alert state.
- Confirm the workspace that owns the related investigation.
- Remove obsolete monitors to avoid depending on a retiring service.
- Follow Security Watch release and migration guidance when it is available.
