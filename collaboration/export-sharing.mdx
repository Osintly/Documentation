Osintly supports result, card, map, and investigation exports. Organization searches are visible in shared history and can be organized in an organization investigation.

---

## Export formats

| Format | How to access | Notes |
|---|---|---|
| **JSON** | Card expansion modal | Available per card. Exports the raw structured data returned by that provider. |
| **CSV / JSON (map)** | Map synthesis block | Exports the geographic data points from the map view. |
| **PDF / JSON / CSV / Markdown** | Result page header (`Export`) | Choose a format and the Osintly results, leak results, or both when available. DOCX is not currently offered in this menu. |

---

## Exporting a single card

1. Click any module card to open the expansion modal.
2. Use the export option in the modal to download the card's data as JSON.

This is available on paid app plans for full result pages and does not consume additional credits. Free previews do not include exports.

---

## Exporting map data

When a map panel is available on the result page:

1. Open the map panel menu.
2. Export map points as **JSON** or **CSV**.

This export includes geocoded markers derived from location fields in result cards.

---

## Exporting from the result header

From the result page header, click **Export** to access available output options.
 

---

## Complete organization history export

In an organization, select 1–100 saved searches or tool results in [History](/guides/history) to download their complete payloads as a JSON archive. This bulk action requires `history.export` permission and is separate from the per-result PDF/JSON/CSV/Markdown menu. Personal history does not provide the organization archive. The export is logged in [Organization activity](/collaboration/organization-activity).

---

## Sharing in an organization investigation

Select an active organization and create an [investigation](/collaboration/investigation-projects) to group searches, notes, and files for its members. Organization searches are also visible in shared history. Preserved Solo and legacy Team projects in Personal are export-only and can be downloaded as ZIP; they are not the workflow for creating new shared investigations.

---

## Export and credits

Exporting from an existing result page does not consume credits. The result is already saved - no new query is run on export.
