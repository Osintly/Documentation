**Investigations** group searches, notes, and files. New investigations are created in an active **organization** workspace. Investigations are no longer included with any individual subscription, including Standard, Pro, and Ultimate. A Personal workspace may still list older Solo and legacy Team investigations, but these are **export-only**: their detail pages cannot be opened and they cannot be edited, receive new searches, or accept uploads.

## Create an organization investigation

1. Select an active organization in the workspace menu and open **Investigations**.
2. Choose **New Investigation**, add a title and description, and save. The organization plan controls how many investigations can be created.
3. Open the investigation to add searches, write Markdown notes, and upload files. Searches launched in an organization project stay within that organization's history.

Organization owners, admins, and members can create and update investigations when the organization is active. Owners and admins can delete them. All organization members can read them. The investigation page has **Searches**, **Files**, and **Notes** tabs. You can filter searches and files by text; Files also supports type filters. Notes support editing and preview.

The list separates **All Investigations**, **Active**, **Completed**, and **Archived**. A project can include a cover image and description. Creation and update dates displayed by Osintly are in **UTC**.

## Reports and audit history

Use **Export investigation** on the detail page to download a PDF summary of the project, its searches, notes, files, and storage usage. For organization investigations, owners and admins can open the project audit log and export its entries as JSON or CSV. The project audit log covers recorded project events; the broader [Organization activity](/collaboration/organization-activity) page covers actions across the workspace.

## Export an older Personal or Team investigation

1. Switch to **Personal** and open **Investigations**. Existing Solo and legacy Team investigations appear in a preservation list.
2. Select **Export ZIP** beside each investigation. You do **not** need an organization subscription to export an investigation you can access.
3. Keep the downloaded ZIP in your own storage. The interface warns that legacy investigations will be removed in the future, without giving a removal date. Confirm that the archive opens and contains what you need before choosing **Delete**; deletion is optional and permanent.

Each ZIP contains `investigation.json` (project metadata and counts), `notes.md`, `searches/index.json`, individual search JSON files, `files/index.json`, and downloadable attachments. Search exports include complete results when the complete-result service is available. If a result cannot be reconstructed, the stored search is exported instead. If an attachment cannot be downloaded, or a complete search falls back to stored data, the ZIP includes `export-warnings.json` describing the affected item. Review that file and contact [support](https://osint.ly/support) if essential data is missing.

Changing a Personal plan does not restore Investigations. An Organization plan permits **new shared investigations**, but it does not migrate the older Personal or Team projects into that organization.

For saved searches outside a project, see [Search and tool history](/guides/history). Organization search results can be associated with an eligible organization investigation; legacy Team collaboration remains a separate historical scope.
